The C# runtime, Godot client, standalone JavaScript encounters, and Python extractor have [run instructions](../README.md).
The dated design notes sometimes describe goals later prototypes only partially implemented.

The creator’s separate backups also preserve historical builds, extracted scenes, mod assets, and experiments.
The RobCo content archive contains a namespace tool, authoring demo, catalogs, and character records.
The original Relic core and standalone viewer source remain unlocated.
