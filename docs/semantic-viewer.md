# Semantic Viewer · the Grizzly7 experiment

2Shay used Grizzly7, a Fallout 4 modded weapon, as the test input. The question was simple.
Could an NPC describe an unfamiliar item just by looking at what the player held?

## What survives

The recovered render sheet shows seven views: front, rear, left, right, both three-quarter angles, and top.
An eighth panel supplies size, game weight, and class. Those values are metadata.
The grey render shows a scope above the body. Its actual finish cannot be read from these views.
The Mac backup also contains the mod files and an extracted OBJ mesh.

A search of the connected Drive and Mac backups found the render and design notes.
The original viewer executable, source, model configuration, and generated tag output remain unverified.

## Intended workflow

1. Import an item mesh from the player's own game or installed mod.
2. Render several angles so a feature hidden on one side appears on another.
3. Give those views to a vision model. Record visible traits alongside the item identifier.
4. Give the NPC the traits of items it can currently see. Dialogue can mention those details.
5. Let game rules combine traits across items, outfits, and the observer’s tastes.

For Grizzly7, “there’s a scope on top” is supported by the surviving render.
“Gold-plated” would require colour or material evidence. It would be speculation from this sheet.

2Shay’s design examples use gilded weapons for a possible +5 coolness bonus.
Matching Gothic weapon and clothing styles could earn +20 suave. Clashing styles could incur a penalty.
These illustrate proposed rules. No recovered test demonstrates those scores.

The archived image and notes live in the creator’s Drive backup.
